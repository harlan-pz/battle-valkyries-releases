## 安装 / Installation

1. 退出游戏，按对应版本说明安装前置 Mod。
2. 将下载的 Mod ZIP 文件放入 Battle Brothers 的 `data` 目录，保持 ZIP 格式。
3. 更新时移走同一 Mod 的旧版本，避免重复加载；中文包与英文包选择其一。

Open a release and download the Mod ZIP for your language from **Assets**. Follow that release's dependency and compatibility notes. Close the game, place the ZIP in the game's `data` folder without extracting it, and remove older copies of the same Mod before updating. Use one language variant at a time.
